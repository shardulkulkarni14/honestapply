# Hired with honestapply

People who landed a role with honestapply somewhere in the loop, in their own words.

Rules, so the number stays honest:

- **No entry, no count.** The badge in the README reads `docs/hired-count.json`, which only
  changes when a card is added here.
- **A human verifies each card.** Open an issue with the
  [I got hired](https://github.com/shardulkulkarni14/honestapply/issues/new?template=i-got-hired.yml)
  template; a maintainer adds it after a look at the story.
- **You choose how visible you are**: handle, first name, or anonymous. Nothing is defaulted
  to the most exposed option, and company names are never required.
